Daten laden

Der Speedreader zeigt die KI-Felder der Kapitel (Zusammenfassung, Thesen, …) als Schnelllesen vor dem Originaltext. Dafür braucht er einmalig die Datei daten.json, erzeugt am PC mit export_daten.py. Sie wird danach auf diesem Gerät gespeichert, auch ohne WLAN.

Optional für die Ansicht Original (Volltext der Kapitel): den Ordner buecher aus dem Export importieren.
